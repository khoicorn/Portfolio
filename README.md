# Khoi Ngo · Senior Data Analyst Portfolio

Case studies of my data, BI and automation work: Power BI dashboards, Python data pipelines, API integrations, chat bots hosted on AWS EC2, and a few personal apps.

Company projects are shown as sanitized case studies. Their pictures are recreated with fictional sample data, and no client names, internal links or source data are published.

## What is inside

- **Home:** featured projects and the skills each one proves.
- **Projects:** search and filter all projects by category or tool.
- **Case study pages:** the problem, what I built, the result, the tools and what each one does, and how the system works step by step.

## Built with

React 19, TypeScript, Vite, Tailwind CSS 4 and Motion. Project content lives in `src/data/projects.ts`. Deployed to GitHub Pages with GitHub Actions.

## Run locally

```powershell
npm install
npm run dev
```

Production build:

```powershell
npm run build
npm run preview
```
